MCA_WLTNT: Lookup-Table-Free and Triangle-Free Marching Cubes

From Marching Squares to Point-Based Implicit Surface Reconstruction
---

1. Introduction

Classical Marching Cubes algorithms rely on predefined lookup tables and triangle-based mesh construction. While effective, this introduces discrete topological dependency and computational overhead.

We propose MCA_WLTNT, a geometry-first formulation that eliminates both:

  • Lookup tables
  • Triangle mesh construction

Instead, the method directly reconstructs implicit surfaces using point-based geometric sampling.

---

2. Implicit Surface Formulation

The surface is defined as:

\[ f(x,y,z)=0 \]

Each voxel contains 8 vertices and 12 edges. A surface crossing is detected by sign changes:

\[ f(P_1)\cdot f(P_2) < 0 \]
---

3. Geometric Intersection

The intersection point is computed by linear interpolation:

\[ P = P_1 + t(P_2 - P_1), \quad t = \frac{|f(P_1)|}{|f(P_1)| + |f(P_2)|} \]

This produces iso-points satisfying \( f(P) \approx 0 \).

---

4. Core Idea: Point-Based Surface Representation

Unlike classical Marching Cubes, MCA_WLTNT does NOT construct triangles.

Traditional pipeline:

Edge intersections → Lookup table → Triangles → Mesh

MCA_WLTNT pipeline:

Edge intersections → Iso-points → Dense point cloud → Surface approximation

Thus, the surface is represented as a continuous dense point set.
